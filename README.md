# Number Guessing Game 🎯

A simple Python number guessing game where the computer randomly selects a number between **1 and 100**, and the player tries to guess it.

## 🎮 How It Works

- The computer generates a random number between 1 and 100.
- The player enters a guess.
- If the guess is too high, the game gives a hint to guess lower.
- If the guess is too low, the game gives a hint to guess higher.
- The game continues until the correct number is guessed.
- The total number of attempts is displayed at the end.

## 🛠️ Technologies Used

- Python
- `random` module

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

3. Open the project folder:

```bash
cd Number-Guessing-Game
```

4. Run the Python file:

```bash
python number_guessing_game.py
```

## 📌 Example

```text
Guess the number: 50
Guess a higher number

Guess the number: 75
Guess a lower number

Guess the number: 63
Congratulations! You guessed the number in 3 attempts.
```
